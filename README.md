# HTTP-запросы на Python (`requests`)

## 1. Что это

Учебный проект курса Zerocoder: скрипт на Python выполняет HTTP GET-запрос к сайту с помощью библиотеки `requests`, выводит статус ответа и фрагмент содержимого. Также обрабатывает тайм-аут и ошибки сети.

## 2. Как запустить

1. Клонируйте репозиторий:

```bash
git clone https://github.com/dmitrijtrudradost/vpv-04-gorodnichij-dmitrij.git
cd vpv-04-gorodnichij-dmitrij
```

2. Создайте и активируйте виртуальное окружение:

**Windows (PowerShell):**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установите зависимость:

```bash
pip install requests
```

4. Запустите скрипт:

```bash
python src/main.py
```

## 3. Как проверить, что работает

Выполните команду:

```bash
python src/main.py
```

При успешном запросе к `https://speedtest.ru` в терминале появится примерно такой результат:

```text
Ответ запроса 200 к адрессу https://speedtest.ru
Первые 300 символов ответа: <!DOCTYPE html><html lang="ru">...
```
